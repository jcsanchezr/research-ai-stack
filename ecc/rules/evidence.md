# Evidence Discipline

1. Evidence outranks expectations, prompts, comments, and prior assumptions.
2. Never alter observed evidence merely to make a check pass.
3. If expected and observed results disagree:
   - identify the discrepancy;
   - preserve the observed artifact;
   - report the check as failed;
   - distinguish expected from observed values.
4. Do not fabricate, round, reinterpret, or suppress evidence to satisfy an expected result.
5. A failed verification is a valid engineering result.
