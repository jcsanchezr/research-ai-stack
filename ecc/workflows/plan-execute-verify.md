# Plan → Execute → Verify

For non-trivial tasks:

## 1. Plan
Define:
- objective;
- steps;
- affected artifacts;
- constraints;
- verification criteria.

## 2. Execute
Perform the planned steps in order.

If execution reveals conflicting evidence:
- stop relying on the invalid assumption;
- revise the plan;
- continue from the new evidence.

## 3. Verify
Inspect the resulting state independently.

A task is complete only when:
- the requested artifact/state exists;
- required invariants hold;
- verification succeeds.

## 4. Report
Report:
- what changed;
- what was verified;
- any remaining limitations or failed checks.
